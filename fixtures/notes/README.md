# 阅读，是一场安静的探索

我们记下一个想法，通常不是因为已经想明白，而是因为它值得再想一遍。

这里是一座小小的数字花园。没有信息流，没有未读数，也没有必须完成的清单。只有一些慢慢生长的笔记，和它们之间尚待发现的联系。

> “The more I read, the more I acquire, the more certain I am that I know nothing.”
>
> — Voltaire

## 从一条小径开始

不必从头读到尾。打开一篇感兴趣的笔记，沿着链接走一段，再回到原来的地方。知识的意义，常常出现在两篇笔记相遇的时候。

- **理解一个方法** · 从 [[01 思考的方法/渐进式总结|渐进式总结]] 开始，把阅读变成自己的语言。
- **观察日常细节** · 去 [[02 观察与记录/城市里的蓝色|城市里的蓝色]] 里散步，留意那些平时没有看见的颜色。
- **留一点空白** · 读一读 [[03 The Reading Room/On paying attention|On paying attention]]，给注意力一处安静的落点。

## 让笔记彼此照亮

单独的笔记像一颗星，链接则是星与星之间的线。我们并不急着为它们画出最终的星座。今天关于设计的一个观察，也许会在几个月后，回答另一个关于生活的问题。

> [!NOTE] 关于这个空间
> 这是一个用于体验 Ocelot 的合成知识库。这里的文章、目录和附件均为示例，与你的私人笔记无关。

### 写给未来的自己

好的笔记不需要面面俱到。一个清楚的问题，一段具体的观察，一个能让自己重新进入现场的例子，已经足够。

| 留下来 | 为什么 |
| --- | --- |
| 一个具体的问题 | 比一个宽泛的主题更容易重新开始 |
| 一段自己的解释 | 理解来自重新表达，而不是收藏 |
| 一条有意义的链接 | 为未来的发现留下一扇门 |

### 阅读的节奏

中文需要呼吸，英文需要韵律。合适的行长、松弛的行距，以及不争抢注意力的界面，让文字回到中心。

Read slowly. Follow a thought. Leave room for another.
