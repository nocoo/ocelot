# 04 · 实现与本地验收

状态：**本地实现与验收完成；首次上线见 09**

更新：2026-09-11

## 本轮范围

实现可在本机运行的完整阅读闭环，并保留可部署的生产 Worker 入口：仓库添加、
切换与移除，目录树，安全 Markdown 阅读，附件，按需缓存，更新提示，PAT
轮换状态，明暗主题和移动端阅读。使用合成数据，不复制私人 vault。

用户明确接受细粒度 PAT 与定期轮换，特别要求提醒和加载效果自然、克制。
生产凭据通过 Worker Secrets 配置，前端不提供 token 输入框。

## 本地与生产

- 生产入口验证 Cloudflare Access JWT，只调用 GitHub API，使用 D1/R2 bindings。
- 独立本地入口由 `wrangler dev --local` 运行，监听 loopback；使用本地 SQLite
  D1、磁盘持久化 R2 和可控 GitHub mock。生产入口不导入 mock 或本地认证旁路。
- Vite 开发服务器将 `/api` 请求代理到本地 Worker，前端正常热更新。
- 一个开发命令负责应用本地 migrations、加载合成数据并启动两个进程。
- CI 和浏览器测试使用独立的临时本地数据库，避免污染开发者已有数据。
- Mock 覆盖公开/私有仓库、超过一千个文件、中文和空格路径、多层目录、双链、
  图片、callout、代码、表格、Mermaid 和公式。保留至少两个 Git 版本供更新验证。
- 本地场景可切换：正常、慢请求、临近到期、凭据失效、限流、上游离线及新提交。
  这些控制仅在本地入口注册。

## 分层与契约

| 层 | 职责 |
| --- | --- |
| Models | 仓库路径、版本差异、链接解析、文档元数据、阅读时间、连接状态 |
| ViewModels | 仓库/文档选择、异步请求竞态、更新应用、错误恢复、阅读偏好 |
| Services | 类型化 HTTP 客户端、浏览器导航与非敏感偏好 |
| Views | Basalt 外壳与控件、Pierre 目录树、Kami 排版、弹层与可访问反馈 |
| Worker | 身份验证、输入限制、GitHub 客户端、D1 状态和 R2 读写 |

数据库 migrations 是本地和生产共同的 schema；合成仓库种子单独存放，
不写入生产 migrations。API 对仓库 URL、ID、分支、快照和文件路径验证后
才访问上游。正文与附件绑定同一 tree 快照；旧文章不会被后台刷新替换。

## 连接与加载体验

- 健康连接仅在侧栏显示小型状态。到期前 7 天显示轻量提醒；详细信息在连接面板。
- 优先使用 GitHub 返回的到期信息，允许部署配置补充到期日；缺失时如实显示未知。
- 凭据失效显示“连接需要更新”，保留已经显示的文章；不将 403 限流误判为过期。
- 更新服务端 PAT 后可以点击“重新检查”；不要求重新添加知识库。
- 初次打开用保留标题、段落和目录尺寸的骨架；切换文件保留原文直到新文档准备好。
- 检查更新只在工具栏显示局部状态。发现更新后由用户应用，保留路径、目录展开与
  尽可能可恢复的阅读位置。快速连续切换不能被较晚返回的旧请求覆盖。
- 错误信息可操作，使用本地化状态文案；不向用户显示上游响应正文、token 或堆栈。
- 支持键盘、减少动效、清晰焦点和独立 disabled tokens。

## 视觉实施

使用 Basalt `AppShell` / `Sidebar` / `AppHeader` 组织空间。冷蓝灰强调色配
干净纸面，以明度和边界区分层次；阅读正文采用衬线字体，界面采用系统无衬线。
借鉴 Kami 的长文层次与中英文节奏，保留语义强调，调整为屏幕阅读尺寸。
Pierre 使用公开 CSS variables 与 React API，关闭文件修改能力。

桌面提供目录、正文和文章大纲；窄屏将导航收纳为抽屉。浮层使用轻阴影，正文
依靠留白。动画不挤动文章；自动化浏览器验收包含 light/dark/mobile 截图。

## 验收门禁

1. TypeScript 7.0.2 类型检查、Biome、生产构建与 Worker dry run。
2. 非 View 的第一方运行时代码四项 UT 覆盖率均 ≥95%，包括 Worker；
   覆盖统计包含未执行源码，不以 View 承载业务来规避测试。
3. 安全路径覆盖 Access JWT 签名/过期/错误 audience、路径穿越、隐藏文件、
   凭据失效后缓存访问、Markdown 脚本输入和原始附件类型。
4. 使用真实本地 SQLite D1/R2 验证重复读取命中缓存、304、版本更新、并发检查、
   撤销访问、限流退避和移除仓库。
5. Playwright 验证仓库管理、目录、双链、搜索、加载、轮换提示、更新、主题、
   移动端和键盘交互；检查浏览器错误及基本可访问性。
6. Husky 与 CI 复用项目检查命令；按功能边界原子提交到 `main`。
