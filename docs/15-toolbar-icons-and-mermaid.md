# 15 · 图标工具栏与 Mermaid 兼容性

状态：**已实现并完成本地验收；生产交付以对应 main CI/CD 为准** · 2026-09-13

## 用户要求

- 重新设计右上角按钮区，全部使用 Lucide 图标，不显示按钮文字。
- 替换当前站外跳转图标；阅读偏好保留 Aa 的识别方式，但改用 Lucide 图标。
- 修复部分 Mermaid 无法正确展示的问题，包括带中文、竖线、比较符和 HTML
  换行的 `stateDiagram-v2`。

## 实施决定

界面沿用已发布的 Basalt 2.1.7 `AppHeader`、`Button` 和 `Tooltip`，参考
`../basalt/INTEGRATION.md` 与安装包 `ai/RECIPES.md`。阅读器选项与全局操作
保留无障碍分组、分隔和窄屏换行，图标统一尺寸、线宽与点击区域。阅读偏好采用
`CaseSensitive`，当前文件的站外跳转采用 `ArrowUpRight`；其余操作使用相应
Lucide 图标。更新数量通过提示和无障碍名称传达，检查中、更新可用和开关状态
仍有明确反馈。图标统一为 18px、1.75px 线宽，桌面按钮为 34px，手机为 32px，
相邻按钮间距 4px；键盘焦点使用一层清楚的描边。固定依赖版本，不添加图标依赖。
Safari 点击按钮时不自动建立焦点；图标按钮和图片入口显式记录点击焦点，
让关闭偏好、导航或灯箱后能回到正确的入口。

只读核查本机笔记并在隔离的阅读器内复现：同篇 7 张图中，3 张流程图的图片
无法解码，1 张思维导图包含解析器不接受的语法。用户提供的状态图语法有效；
其 SVG 的固有尺寸约为 `136 × 150`，明显小于实际布局，放大预览会受此影响。
排除语法错误后，根因与决定如下：

- Mermaid 12.0.0 已弃用图类型内的 `htmlLabels`；全局默认值覆盖现有的
  `flowchart.htmlLabels: false`。HTML 标签中的换行被序列化成未闭合的
  `<br>`，造成 SVG XML 解码失败。改用全局 `htmlLabels: false`，并保护
  该配置不被笔记指令覆盖；原有严格安全配置与图片隔离继续生效。
- Mermaid 为响应式布局生成百分比尺寸的 SVG；作为图片使用时，浏览器会
  回落到约 150px 的固有高度。服务根据生成 SVG 根元素的有效 `viewBox`
  设置明确的宽高，正文继续响应式缩放，灯箱可以按真正的布局尺寸查看。
- 渲染与图片 URL 生成由 service 负责，Views 处理生命周期、加载和回退。
  图片解码失败也回退到可读源码；语法无效的图示继续展示源码，不猜测改写
  笔记内容，不放宽 CSP 或执行笔记中的 HTML。

公开回归样例使用原创的合成状态图，覆盖同类语法；不复制本机私有知识库的
正文、路径或凭据，也不修改来源知识库。

## 验收范围

- 工具栏：无可见按钮文字、图标一致、悬停与键盘提示、开关/禁用/更新状态；
  320–1440px、明暗主题、移动端与桌面无溢出。常规页面使用完整 axe 检查；
  临时 Tooltip 按 WCAG 2.0–2.2 检查，并验证 `aria-describedby` 关联。
- 图示：状态图节点与连线标签、中文/竖线/比较符/换行完整显示；现有流程图、
  多图、主题切换、放大预览与错误源码回退。
- 工程：类型、Biome、非 View runtime 四项覆盖率 ≥95%、生产构建、Worker
  dry run、绑定类型无差异、完整浏览器回归与安全扫描。
- 交付：可验证的原子提交推送到 `main`，核对相同提交的 CI/CD 与生产版本。
