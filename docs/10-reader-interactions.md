# 10 · 阅读器交互与典型样例

状态：**九项修复及追加的控件分组、进度位置已实现并通过本地验收** · 2026-09-12

## 用户要求

1. 文章右侧导航对齐 Basalt 模板，切换章节有动画。
2. 超长目录能够独立上下滚动，最后的章节也能选择。
3. 阅读器默认限宽，提供全宽选项。
4. 提供原始 Markdown 查看选项。
5. sidebar 底部头像与姓名布局符合 Basalt，接入公开作者资料服务。
6. 消除侧栏与正文交界处偶发的贯穿高度高亮。
7. 阅读器可以一键回到顶部。
8. 点击文章图片进入覆层 lightbox 放大查看。
9. 本机 mock 包括超长文章、多级标题和典型图文混排情况。

追加反馈已接受：阅读进度放到右侧目录上方；全宽不能只藏在 Aa 偏好里，
工具栏直接显示“全宽”开关，同时保留偏好面板中的设置。
阅读器选项与全局操作分组：全宽、字号、Raw、复制链接和文章大纲置于具名的
阅读器控件组，与更新、主题、本地场景和源码入口通过底色、边界及间距区分。
窄屏将阅读器控件单独一行，不能通过挤压或隐藏让全宽入口再次难以发现。

## 核查与实施约定

- 已安装的 `@nocoo/basalt 2.1.7` 提供 `TableOfContents` /
  `TableOfContentsItem`。本轮开始时目录仍是手写结构，现已改用发布包组件，
  加入连续移动的活动指示条与平滑章节滚动；减少动态效果时关闭动画。
  目录高度以实际阅读容器为限，列表独立滚动，进度与回顶操作保留可达性。
  窄屏目录用 Basalt 具名覆层，支持键盘、Escape 和焦点恢复。
- 默认保持舒适行宽；工具栏直接切换全宽，偏好面板同步状态。全宽偏好只写
  本机浏览器，字号继续沿用现有偏好。阅读进度位于右侧目录上方。
  Raw 显示已授权、已加载的 `Reading.content`，包括 frontmatter 与原始标题，
  作为转义文本呈现，不再请求 GitHub、不执行 HTML，也不写入笔记内容。
  附件不提供 Markdown 模式；切换笔记恢复渲染模式。
- 新的宽度、阅读模式、目录和灯箱交互状态由 Reader ViewModel 管理；
  View 只组合 Basalt 控件、呈现状态和处理 DOM 测量、滚动及焦点。
- 现有服务端已经实现规范化邮箱的 UTF-8 SHA-256 查询与同源头像代理。
  2026-09-12 公开查询实测：带明确客户端标识与 JSON Accept 的请求返回
  `200`、`Zheng Li` 与 `https://b.no.mt` 的头像；首次 Python 默认请求为
  `403`，不能把传输失败判定为资料不存在。补充明确请求标识和 429 的短暂
  退避缓存，保留服务超时、大小限制、HTTPS 固定 origin、禁止重定向和回退。
  只发送经 Access 验证的邮箱哈希，头像/资料缓存访问前继续验证身份。
  测试仅用合成邮箱、姓名和图片，不记录真实头像路径或身份凭据。
- 底部继续使用 `SidebarFooter`、`SidebarUser`、`Avatar`，恢复模板的
  字号、间距与头像大小，清除 standalone CSS 模式下段落默认 margin 的干扰。
  收起状态也保留身份头像；品牌位置仍固定在左侧 24px。
- Basalt `SidebarProvider` 的调整宽度 separator 是贯穿高度的可聚焦元素，
  当前通用 `:focus-visible` 给它整条描边。改为局部手柄焦点提示；正文的
  程序焦点目标不画整块容器描边，普通链接和控件仍保留键盘焦点样式。
- 增加阅读容器内可见的 Basalt 回顶按钮，长文章不必先滚到底部。
  图片复用已经通过 URL/附件边界的资源，用 Basalt Dialog 放大，支持适应
  窗口、原图尺寸滚动、关闭按钮、Escape、遮罩关闭与焦点返回。
  Markdown 图片、图片附件和安全生成的 Mermaid 图示使用同一入口；
  不放宽 CSP，不增加任意 URL 代理。
- 扩展现有确定性 fixture 生成器：超长中英文章、足够超出屏幕的分级目录、
  横图/竖图/方图/超长图/小图、带链接图片、图文混排、宽表格、长代码、
  引用/callout/数学/图示和缺失图片；从本地花园入口能发现这些样例。
  所有文字与位图为原创合成数据，不访问或复制私有知识库。

## 验收计划与证据

- UT：宽度存储边界、模式切换与导航清理、灯箱状态、精确 SHA-256 向量、
  资料失败/429/缓存恢复及身份先于缓存；全部非 View runtime 四项覆盖率 ≥95%。
- 浏览器：长目录滚轮和键盘末项可达、活动条过渡、文章跳转、减少动态效果、
  回顶、全宽与重载、Raw 原文与 HTML 转义、灯箱缩放/滚动/关闭/焦点、
  头像正常与失败、局部 separator 焦点、深浅主题与窄屏 axe、可见文字 ≥11px。
- 工程：TypeScript、Biome、完整覆盖率、生产构建、Worker dry run、
  Playwright、OSV / Gitleaks；原子提交与推送 `main`，检查对应 CI/CD。
